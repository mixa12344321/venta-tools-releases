# VENTA — приложения и обновления

Публичный канал готовых приложений для Windows x64. Здесь размещаются дистрибутивы, описания выпусков и контрольные суммы. Проекты с исходниками, пользовательские данные и ключи в этот репозиторий не публикуются.

## Установить лаунчер

1. Откройте [последний выпуск](https://github.com/mixa12344321/venta-tools-releases/releases/latest).
2. Скачайте `VentaLauncher-1.0.0-win-x64.zip` и распакуйте целиком.
3. Запустите `VentaLauncher.exe`. Чтобы установить его на ПК и создать ярлыки, запустите `Установить.cmd`.
4. Откройте **Обновления**: проверьте версии, установите нужные приложения или обновите установленные.

Лаунчер поддерживает светлую и тёмную темы, поиск, недавние запуски, установку и обновление из GitHub Releases и офисного Nextcloud. Права администратора не нужны. Настройки и приложения хранятся в профиле текущего пользователя.

## Приложения

| Приложение | Назначение |
|---|---|
| LabelDesk | Макеты и печать товарных этикеток, QR и штрихкодов |
| DIN Label Studio | Маркировка DIN-реек и щитов |
| Завод — Rust / WebView2 | Сайт, габариты, стоимость и брошюры |
| Менеджер отгрузок | Отгрузки, путевые листы и документы |
| Сервер отчёта | Общий веб-отчёт по товарным позициям |

**Лаборатория распространяется только в версии Rust / WebView2.** При наличии старой Electron-версии лаунчер требует переход на Rust и перенаправляет пользовательские ярлыки. Старый профиль сохраняется; вход на сайт и подключение Битрикс24 при необходимости выполняются в новой программе. Для Rust нужен Microsoft Edge WebView2 Runtime.

Перед обновлением закройте соответствующую программу, включая значок в трее. Лаунчер проверяет SHA-256 архива и каждого файла, сохраняет предыдущую версию и восстанавливает её при ошибке замены. SHA-256 проверяет целостность; приложения распространяются без подписи издателя Windows.

Сервер отчёта устанавливается и обновляется на одном выбранном компьютере. Коллеги открывают адрес этого компьютера в браузере. Адрес меняется в настройках карточки отчёта; код доступа выдаёт сервер.

`catalog.json` в последнем выпуске — каталог версий для лаунчера. ZIP-архивы содержат готовые приложения и необходимые ресурсы выполнения; отдельные архивы проектов с исходниками не публикуются.
